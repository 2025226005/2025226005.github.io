SSAIL Editor Guide

This editor saves content directly to the website’s GitHub repository. Use a GitHub fine-grained personal access token with write access to that repository. No additional service account is needed.

Sign in

  1. Open /admin/ on the published HTTPS website.
  2. Enter your GitHub access token and click Open editor.
  3. Select a collection, edit an existing entry or create a new one, then click Publish.
  4. Wait for Publish SSAIL website in GitHub Actions to finish, then refresh the public website.

The token stays in this window’s memory. Enter it again after reloading or closing the page.

Add an undergraduate year or student

  1. Select Undergraduate researchers → New Year.
  2. Enter the year, for example 2027.
  3. Add members with their names, photos, roles, education and email addresses, then publish.

A new year tab appears first. To add a student to an existing year, open that year and add a member. New members appear first within their group. The first year tab opens by default unless the visitor follows a link to a specific year. Create a new year instead of renaming an existing year.

Add publications and news

For a publication, select its type and enter the complete citation. Italics and links are supported. New publications appear first within their type. For news, enter the full article; the optional home page introduction is separate. New articles appear first. The first three articles appear on the home page. Editing an existing entry keeps its position.

Change the display order

  1. Open a collection’s list page and click ↕ Reorder at the bottom right.
  2. Choose the items to reorder: publication type, news articles, year tabs, school groups or members in a particular group.
  3. Drag a row, or use ⇈ ↑ ↓ ⇊ to move it to the first, previous, next or last position.
  4. Click Save order, then wait for GitHub deployment. Reset discards unsaved moves.

There is no numeric display-order field. In a member editing form, you can also drag member handles and publish the entry. Reopen a collection to refresh its main list after saving an order. If another editor changed the repository, reload the order list before trying again; the order editor does not overwrite concurrent changes.

Create or replace an access token

  1. Sign in to the GitHub account that owns this repository and open Create a fine-grained access token.
  2. Choose the expiration that suits your access policy. The link preselects 90 days; your selected expiration applies.
  3. Under Repository access, choose Only select repositories and select 2025226005.github.io.
  4. Set Contents → Read and write. Metadata read access is included automatically.
  5. Click Generate token and keep the value in your password manager. Paste it only in the admin sign-in field.

Content and recovery

  • The editor covers undergraduate researchers, current members, alumni, publications and news. The professor introduction, Research, Teaching and Contact remain editable in the HTML source.
  • Photos, contact details and text are published on the website and in its public repository.
  • Images are stored under uploads/cms/. Folder-entry order is stored in content/order.json; member order follows the member list in each content file.
  • If publishing fails, check the new GitHub commit and its Actions result. The previous successful deployment remains visible until a new one succeeds.
  • Recover mistakes through GitHub history, preserving other editors’ newer changes. Sign out on shared computers.
