SSAIL 콘텐츠 관리

기존 GitHub 계정에서 홈페이지 저장소용 관리 키를 발급해 접속합니다. Cloudflare 가입이나 인증 서버는 필요하지 않습니다. 최초 게시 설정은 프로젝트의 ADMIN_SETUP.md를 참고하세요.

관리 키 발급 (처음 한 번)

  1. 홈페이지 저장소 소유자인 2025226005 GitHub 계정으로 로그인하고 Fine-grained 관리 키 만들기를 엽니다.
  2. Repository access에서 Only select repositories를 고르고 2025226005.github.io를 선택합니다.
  3. Repository permissions의 Contents → Read and write를 확인합니다. Metadata 읽기는 자동으로 포함됩니다.
  4. Generate token을 누르고 표시된 키를 복사해 비밀번호 관리자 등에 보관합니다. 채팅이나 홈페이지 파일에 붙여 넣지 않습니다.

접속과 저장

  1. 게시된 HTTPS 홈페이지의 /admin/에 접속합니다.
  2. 관리 키를 입력하고 관리 화면 열기를 누릅니다.
  3. 항목을 선택해 수정한 뒤 Publish/게시를 누릅니다. 저장 내용은 GitHub에 기록됩니다.
  4. 저장소 Actions의 Publish SSAIL website가 성공한 뒤 홈페이지를 새로고침합니다. 저장과 배포는 별도 단계이므로 반영까지 시간이 걸립니다.

새로고침하거나 창을 닫으면 관리 키를 다시 입력해야 합니다. 기본 발급 기간은 90일이며, 만료되면 새 키를 발급합니다.

2027년 학부 연구생을 추가하려면

  1. 학부 연구생 · 연도별 → 새 연도를 선택합니다.
  2. 연도에 2027을 입력하고 구성원 명단에서 항목 추가를 누릅니다.
  3. 이름, 사진, 직위, 학력 등을 입력하고 게시합니다. 여러 학생을 같은 연도에 추가할 수 있습니다.

2027 탭은 자동 생성됩니다. 기존 2019–2026 명단은 유지되며, 연도가 가장 큰 탭이 기본으로 열립니다. 기존 연도의 숫자를 바꾸기보다는 새 연도를 생성해 주세요.

논문과 뉴스

논문은 종류를 고르고 홈페이지에 표시할 인용문 전체를 작성하세요. 뉴스는 본문 전체와 첫 화면용 소개를 따로 입력할 수 있습니다. 표시 순서는 작은 숫자가 먼저이며, 새 글은 기본값 0으로 최상단에 나타납니다. 동일한 순서라면 파일명 순서입니다.

주의사항

  • 일반 방문자도 관리자 페이지의 주소는 열 수 있지만, 저장소 편집 권한을 가진 키 없이는 내용을 저장할 수 없습니다.
  • 사진과 연락처 등 입력 내용은 공개 홈페이지와 공개 저장소에 남습니다. 공개 가능한 정보만 입력하세요.
  • 이 버전의 관리 대상은 학부 연구생, 현재 구성원, 졸업생, 논문, 뉴스입니다. 교수 소개·Research·Teaching·Contact는 기존 HTML에서 수정합니다.
  • 목록 항목 삭제와 변경도 게시하면 반영됩니다. 실수했다면 GitHub 변경 이력을 되돌려 복구할 수 있습니다. 공유 PC에서는 로그아웃하세요.
